# UI 设计语言与交互规范

目标：成熟、克制、现代的个人桌面工作台；强调信息层级、对齐、空间效率和交互连续性。避免泛化 AI 页面、无意义装饰、过多圆角、渐变、嵌套卡片和夸张动画。保持原有数据和交互语义。

## 设计源文件

- src/styles/tokens.css：四主题（editorial/minimal/dark/nordic），语义颜色、字号、空间、圆角、尺寸、动效。
- controls.css + components/ui.tsx：Button、IconButton、Input、Textarea、Select、Checkbox、SearchField、Segmented、Tag；复用 Dialog 与 ResourceMenu。
- interface.css / workspace.css / home.css / motion.css / responsive.css / visual-qa.css：页面构图、交互与兼容层。新增规则前检查现有级联；避免盲目追加高优先级补丁。
- #/design：真实组件预览、四主题隔离，不改用户配置；不是独立重新实现的示例。

## 视觉令牌

基线字号 11/12/13/14/20px，基础间距 4/8/12/16/24px，圆角 5/8/12/16px，控件高度 28/32/40px。动效 100/120/160/220ms（反馈、退场、常规、侧栏）；不对所有属性 transition:all。触屏适当放大点击区域，拖动分隔栏实时反馈，不插值。四主题文字颜色组合目标 4.5:1、焦点 3:1（测试选定组合，不等同完整 WCAG）。支持 forced-colors 和 prefers-reduced-motion。

## 工作台

默认侧栏 208px（可调 160–320），详情 290px（240–400）；宽屏保留自定义偏好。桌面图标轨道收窄时位置稳定，文字独立显隐、不换行。列表独立滚动，标题与分页稳定。批量选择与当前详情选择区分。打开浮层时背景列表 inert，关闭后恢复触发焦点；菜单与原生 dialog 保留键盘行为。

响应式断点：<=650 手机抽屉，651–1000 平板浮层，1001–1199 固定三栏，>=1200 可调宽度，>=1600 宽屏优化。短横屏保留列表滚动，窄屏批量操作独立横向滚动。断点变化需同步 responsive.ts 与 CSS。

## 首页

保留集中式搜索和轻量资源集合；列表/磁贴可即时切换，置顶组仅在未筛选时独立展示，初始 48 条。主题、背景（纯色/纸面/点阵/色晕）、标题、密度、宽度等可调整；首页重置不影响工作台偏好。默认本地图标占位，不请求第三方字体或远端图标；用户主动开启后才请求站点 favicon。

## 验收

小改动检查相关组件与状态；跨页主题/布局变更用现有 browser visual 专项，必要时上传真实截图并人工查看。覆盖四主题、窄屏及低高度、键盘焦点、加载/空/异常、长文本、选中/禁用、减少动态效果。不要以模拟示意图冒充真实运行截图。
