# FluxNav v2.0.0

个人资源工作台的正式设计重构版本，汇总 v1.3–v1.12 的里程碑改进。

- 四主题统一设计令牌与共享组件；可访问的三栏工作台、个性化起始页、列表/磁贴与响应式导航。
- 收藏集层级、手动排序、批量操作、标签治理及撤销；导入预览、逐条容错、选择性恢复。
- IndexedDB v2 增量存储、后台搜索、大型收藏集分批渲染；不改变书签 JSON schemaVersion 1。
- AI 建议需用户确认，凭据不持久化；Gist / 自定义 JSON 同步及可选客户端加密。
- 交互、动画、键盘焦点、高对比度、减少动态效果与窄屏布局改进。

## 使用方式

- 在线：[GitHub Pages](https://weepwood.github.io/fluxnav/)
- `fluxnav-portable.html`：单文件离线版（下载后使用浏览器打开，存储与站点版本不共享）。
- `fluxnav-extension.zip`：解压后在 Chrome / Edge 扩展管理中启用开发者模式并加载已解压扩展。
- `SHA256SUMS.txt`：两个分发文件的 SHA-256 校验值。

## 升级提示

先导出 JSON 完整备份。旧 LocalStorage / IndexedDB 数据会在原站点同一浏览器中迁移；不同域名、文件路径或配置文件的浏览器存储相互隔离。旧版不一定能读取升级后的 IndexedDB。Gist 同步仍非原子条件更新；AI 和同步依赖用户自己的服务、网络与凭据。真实第三方账号连通性和真实移动设备兼容性需要用户环境验证。
